How much do enterprise agent platforms cost in 2026?

Last updated: 2026-11-09

Most enterprise agent platforms now charge mainly for usage: credits per action, per-call units, or compute time. Some add per-user seats on top. Of the 13 platforms in our ranking, Salesforce, Microsoft, AWS and IBM publish the most complete public pricing. ServiceNow, Automation Anywhere, Kore.ai and OpenAI Frontier are priced by quote. All figures below are vendor list prices in USD, taken from official pages on the date checked. Contracts, regions and discounts change the real price.

What drives the real cost

  • Actions, not chats. Salesforce, Microsoft and UiPath charge per agent action or LLM call, so one multi-step task can incur several charges.
  • Model tokens. Developer platforms (AgentCore, Foundry, Agent Bricks, OCI, OpenAI API) bill model inference separately from the agent runtime.
  • Retrieval, memory and storage. Vector storage, indexing and memory are separate line items at AWS, Oracle, Google and Microsoft.
  • Observability and evaluation. AWS bills observability through CloudWatch and charges for evaluations. Databricks bills judge requests.
  • Included allowances. Some licenses, such as Microsoft 365 Copilot for qualifying employee use and the Salesforce editions with bundled credits, offset metered costs.

How to estimate a budget

  1. Pick 2–3 target workflows and estimate monthly runs.
  2. Estimate the steps per run: tool calls, retrievals and model calls.
  3. Multiply by each vendor's published unit rates, and add storage and observability.
  4. For quote-only vendors, ask for the same scenario in writing, including overage rates.

Sources: each vendor's official pricing and licensing pages, listed on our methodology page. We have not run billed workloads ourselves.
